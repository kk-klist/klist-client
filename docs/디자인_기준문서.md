## 2. 공통 컴포넌트 클래스 (styles/index.css 에 정의됨 — 복사해서 조합만)

| 클래스                                     | 뭐가 나오나                                                                    |
| ------------------------------------------ | ------------------------------------------------------------------------------ |
| `kb-page`                                  | 페이지 컨테이너 (max-w 520, 패딩, 세로 스크롤) — **모든 페이지 최상위에 필수** |
| `kb-title` / `kb-section`                  | 페이지 대제목 / 섹션 제목                                                      |
| `kb-card`                                  | 흰 카드 (보더+라운드+그림자)                                                   |
| `kb-chip` / `+ kb-chip--active`            | 아웃라인 알약 칩 / 활성(검정)                                                  |
| `kb-segment` + `kb-segment__btn(--active)` | All·To do·Completed 세그먼트                                                   |
| `kb-cat-label` + `text-kpop` 등            | 장르 라벨 (색만 갈아끼움)                                                      |
| `kb-logo`                                  | 브랜드 그라데이션 사각/원 (로고·아바타)                                        |
| `kb-check` + `--done/--todo`               | 완료 체크 원 (그린/빈 원)                                                      |
| `kb-btn` / `kb-btn--outline`               | 핑크 CTA / 아웃라인 버튼                                                       |

## 3. 레이아웃 규칙

- 하단 내비 5탭: **Home · Bucket · Map · AI · Me** (`AppLayout.jsx` — 활성=`primary`, 비활성=`muted2`, 라인 SVG 아이콘)
- 앱 전체 `max-w-[560px]` 중앙 정렬(폰 프레임 느낌), 콘텐츠 `kb-page`(520px)
- 가로 스크롤 행: `no-scrollbar -mx-5 flex gap-3 overflow-x-auto px-5` (카드가 화면 밖으로 흐르게)
- 온보딩/로그인만 다크(`#16131a` 배경 + 핑크·보라 글로우) — 본편은 전부 라이트

## 4. 페이지 구성 & 담당

| 라우트    | 페이지                                               | 상태                       | 담당        |
| --------- | ---------------------------------------------------- | -------------------------- | ----------- |
| `/home`   | 홈 (인사·진행도넛·체크인·날씨·근처카드·버킷미리보기) | 🎨 디자인 완성/데이터 목값 | 홈 담당     |
| `/bucket` | 버킷리스트 (세그먼트·장르칩·리스트)                  | 🎨 〃 (필터 UI는 동작)     | 버킷 담당   |
| `/map`    | 지도 (카카오맵·검색·Pick·저장·인증)                  | ✅ **백엔드 연동 완성**    | 지도 담당   |
| `/assist` | AI 어시스트 (채팅 UI)                                | 🎨 디자인 완성/정적        | 챗봇 담당   |
| `/my`     | 마이 (프로필·통계·뱃지·설정)                         | 🎨 〃                      | 프로필 담당 |
| `/login`  | 로그인/온보딩 (다크)                                 | 🚧 버튼만                  | 인증 담당   |

**담당자 할 일**: 자기 페이지 파일 열기 → 상단 TODO 주석 확인 → 목값을 API 데이터로 교체 (디자인·클래스는 그대로 두면 됨). API 패턴은 `프론트엔드_기준문서.md` 4장.

## 5. 금지사항 (디자인 흐트러짐 방지)

- 색상코드 직접 사용 금지 — 토큰 이름만
- 새 `.css` 파일 생성 금지 — `styles/index.css` 의 `@layer components` 에만 추가
- 카드/칩/버튼을 새로 만들지 말고 `kb-*` 클래스 재사용
- 아이콘은 라인 SVG(stroke=currentColor) — 이모지는 콘텐츠(날씨·핀)에만
